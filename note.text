* **Réabonnement**

* Assurance
* Droit d'entrée

### Réabonnement

* Automatically set **Droit d'entrée = 0 DH**

* The **Remise** must only be applied to the **Montant de base**.
* The **Assurance** and **Droit d'entrée** must **not** be affected by the discount.
* Currently, the Remise is applied to the **total amount**, which is incorrect.
